# Label the values passed to `reconcile()`

Label the values passed to
[`reconcile()`](https://stbl.wrangle.zone/dev/reference/reconcile.md)

## Usage

``` r
.reconcile_labels(exprs, n)
```

## Arguments

- exprs:

  `(list)` The captured expressions of the values.

- n:

  `(integer(1))` The number of values.

## Value

A character vector of length `n`.
