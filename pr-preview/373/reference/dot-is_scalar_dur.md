# Test for a length-1 duration vector

Test for a length-1 duration vector

## Usage

``` r
.is_scalar_dur(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if `x` is a length-1
[lubridate::Period](https://lubridate.tidyverse.org/reference/Period-class.html)
vector, else `FALSE`.
