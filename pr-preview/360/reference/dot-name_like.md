# Copy x's names onto out, leaving out unnamed if x has none

Copy x's names onto out, leaving out unnamed if x has none

## Usage

``` r
.name_like(out, x)
```

## Arguments

- out:

  `(list)` The object to name.

- x:

  The object to stabilize.

## Value

`out`, named like `x` when `x` has any names.
