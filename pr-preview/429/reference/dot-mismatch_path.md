# Describe the location of the first difference

Describe the location of the first difference

## Usage

``` r
.mismatch_path(x, at)
```

## Arguments

- x:

  The first of the values being reconciled.

- at:

  `(integer)` The position of the difference, from the top.

## Value

A string like `"$a[[2]]"`, or `""` at the top level.
