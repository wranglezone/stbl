# Explain why two lists or data frames can't be reconciled

Explain why two lists or data frames can't be reconciled

## Usage

``` r
.container_difference(x, y, is_df)
```

## Arguments

- x, y:

  The lists or data frames to compare.

- is_df:

  `(logical(1))` Whether `x` and `y` are data frames.

## Value

A single string, or `NULL` if the containers are compatible.
