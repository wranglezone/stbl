# Reconcile values that must be identical

Reconcile values that must be identical

## Usage

``` r
.reconcile_identical(values, path)
```

## Arguments

- values:

  `(list)` At least one value.

- path:

  `(character(1))` The path to `values` within the original values, for
  messages.

## Value

The first value, or a mismatch.
